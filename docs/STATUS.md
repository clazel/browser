# Verification status

What is proven about each crate, measured by CI's full verification on
`main`. CI rewrites this table and both images after every push whose full
verification passes, so they show the last such push and can lag behind
`main`; each crate's current tier is the one its `Cargo.toml` declares.

The images name each tier by what it guarantees
([VERIFICATION.md](VERIFICATION.md#tiers)): **Proven correct** is Tier 2,
**Panic-free** is Tier 1 and **Memory safe** is Tier 0. The table gives the
numbers.
