`entities.json` is the file the HTML Standard publishes at
https://html.spec.whatwg.org/entities.json and links from §13.5 "Named
character references". It is generated by whatwg/html-build's
`entities/build.sh` and checked in there under `entities/out/`; it is
copied here byte for byte from the commit above:

- https://raw.githubusercontent.com/whatwg/html-build/283a3531a61106d07d9a7d9fb3e6f3b9bfd33d70/entities/out/entities.json
- https://raw.githubusercontent.com/whatwg/html-build/283a3531a61106d07d9a7d9fb3e6f3b9bfd33d70/LICENSE

`cargo xtask check` hashes the file and fails if it differs from the line
below, or if the directory holds anything else:

SHA-256: d741d877ac77c4194c4ad526b5b4a19aef8dfe411ab840a466891cdbb9f362e6 entities.json

`xtask/src/entities.rs` turns it into `crates/clazel-html/src/charref/data.rs`
(`cargo xtask tables`): 2231 rows, each a name as the standard's table
lists it (106 of them without a final `;`, the names that may match without
one) and its one or two code points.
