# Wuffs WebP test data (`wuffs-webp`), for `clazel-webp`

Upstream: https://github.com/google/wuffs
Commit: b36a81d3352604fee1fee3661f39909706b1b966
License: MIT or Apache-2.0, our choice (Wuffs' `LICENSE-MIT` at that commit, unchanged, as `LICENSE.md`; `LICENSE-APACHE` is the alternative)

The directory `test/data/` of that commit (`main` on 2026-11-16), the `*.webp` files item 6.8 uses: every `*.lossless.webp` is in; the lossy ones are two small files (`pjw-thumbnail.lossy.webp`, `mona-lisa.21x32.q0.lossy.webp`) kept to test that a lossy file is refused as unsupported (the rest of the lossy files are item 6.9's); `animated-red-blue.webp` is the one animation. Each file is copied byte for byte, unmodified, from `https://raw.githubusercontent.com/google/wuffs/b36a81d3352604fee1fee3661f39909706b1b966/test/data/<name>`.

These stand in for libwebp's test vectors (`chromium.googlesource.com/webm/libwebp-test-data`), which have no licence stated and so cannot be vendored (phase-6.md, 6.1's inventory); the reference outputs are `image-webp`'s (a dev-dependency of `clazel-webp`), not libwebp's `dwebp`.

Provenance, from `test/data/README.md` at that commit: the `*.webp` files were generated by the `cwebp` command line tool from the same images as the GIF and PNG files of the same name: `bricks-*` are encodings of an original photo by Nigel Tao; `harvesters`, `hat`, `hibiscus.regular` and `hippopotamus` are encodings of artworks the Metropolitan Museum of Art lists as public domain; `hibiscus.primitive` is that Tiffany image run through `fogleman/primitive`; `mona-lisa.*` is derived from a Wikimedia Commons photo of the Mona Lisa; `pjw-thumbnail.*` is derived from a photo by Rob Pike; `animated-red-blue.webp` is an original animation by Nigel Tao. Wuffs' README says some files derive from third-party images; these are the ones used here.
